# Política de privacidad

**Última actualización:** 7 de agosto de 2026.

Ecos del Alma es un proyecto editorial automatizado que publica escritos e imágenes en su sitio web y, mediante una integración propia, puede publicar ese mismo contenido en una cuenta de Pinterest administrada por el propietario del proyecto.

## Datos utilizados por la integración

La integración con Pinterest utiliza la API oficial de Pinterest únicamente para autenticar la aplicación, consultar los tableros de la cuenta administradora y crear Pins correspondientes a publicaciones de Ecos del Alma.

La integración no solicita ni almacena credenciales de inicio de sesión de visitantes del sitio, ni está diseñada para recopilar información personal de terceros.

## Credenciales y seguridad

Las credenciales técnicas necesarias para acceder a la API de Pinterest se almacenan como secretos privados de GitHub Actions y no forman parte del código público del proyecto.

## Información publicada

Los Pins pueden incluir el título del escrito, una breve descripción, la imagen editorial generada para la publicación y un enlace hacia la publicación original de Ecos del Alma.

## Servicios de terceros

Pinterest procesa la información que recibe a través de su plataforma de acuerdo con sus propios términos y políticas de privacidad. GitHub aloja el código, ejecuta las automatizaciones y publica el sitio mediante GitHub Pages.
